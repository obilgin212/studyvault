# The prompt

Open a terminal (macOS: Terminal; Windows: Git Bash or PowerShell), `cd` into this folder (the one with this file), run `claude`, and paste:

---

Set up StudyVault for me. Read `setup/SETUP.md` in this folder (and, if this computer runs Windows, `setup/SETUP-WINDOWS.md`, which replaces the steps that differ on Windows) and follow it phase by phase: check and install the prerequisites (ask me before installing anything), interview me so you can personalize it (my name, pronouns, classes, how I learn, metaphor style, college plans), copy the vault to ~/StudyVault, personalize every placeholder, have me sign in to Google Classroom myself in the window you open, configure my core classes, build each class's profile, map and skill tree from my Classroom and textbooks, set up Obsidian and the daily sync, and finish with a short tour. Never type my passwords. Never do my assignments. When something fails, tell me exactly what happened instead of working around it silently.

---

Setup takes about 30–60 minutes, mostly waiting on the first Classroom sync and textbook extraction.
